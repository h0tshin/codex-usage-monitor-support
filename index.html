GETTING STARTED

시작하기

  1. 1

    로컬 사용 기록 준비

    호환 AI 코딩 도구를 설치·실행해 ~/.codex 아래에 JSONL 사용 기록을 생성합니다.

  2. 2

    읽기 권한 승인

    CodeAgentGauge의 환경설정 → AI 코딩 데이터 접근 → Codex 접근 요청을 누른 뒤 미리 선택된 ~/.codex 폴더를 열기로 승인합니다.

  3. 3

    사용 현황 확인

    사용 가능 비율, 갱신 일정과 최근 토큰 사용 추이를 확인합니다.

TROUBLESHOOTING

자주 묻는 문제

사용량 정보가 표시되지 않아요.

환경설정 → AI 코딩 데이터 접근 → Codex 접근 요청을 누르세요. 폴더 선택 창이 기본 위치인 ~/.codex를 가리키면 열기로 승인합니다. 사용 기록이 없다면 먼저 호환 도구를 설치·실행해 기록을 만든 뒤 다시 요청해 주세요.

위젯 목록에 앱이 없어요.

앱을 한 번 실행해 사용량이 갱신될 때까지 기다린 뒤 위젯 편집 화면을 다시 열어 주세요.

오래된 값이 보여요.

앱은 선택한 폴더의 로컬 JSONL 기록을 정기적으로 다시 읽습니다. 선택한 폴더의 접근 권한과 최신 기록 생성 여부를 확인한 뒤 수동 새로고침을 실행해 주세요.

앱 데이터는 어디에 저장되나요?

폴더 접근 권한은 보안 범위 북마크로, 위젯과 최근 사용 현황은 로컬 캐시로 사용자의 Mac 안에만 저장됩니다. 선택한 JSONL 기록과 캐시는 개발자 서버로 전송되지 않습니다.

계정 없이 기능을 둘러볼 수 있나요?

네. 로컬 기록이나 폴더 권한이 없는 화면에서 샘플 데이터로 둘러보기를 선택하면 계정, 로그인 또는 네트워크 없이 모든 주요 화면을 확인할 수 있습니다. 데모 화면에는 샘플 데이터임을 명확히 표시합니다.
