GETTING STARTED

시작하기

  1. 1

    Codex에 로그인

    Mac에 ChatGPT 앱 또는 Codex CLI를 설치하고 ChatGPT 계정으로 로그인합니다.

  2. 2

    앱 실행

    Codex 사용한도를 실행한 뒤 메뉴 막대의 사용량 아이콘을 선택합니다.

  3. 3

    사용 현황 확인

    사용 가능 비율, 갱신 일정과 최근 토큰 사용 추이를 확인합니다.

TROUBLESHOOTING

자주 묻는 문제

사용량 정보가 표시되지 않아요.

ChatGPT 계정으로 Codex에 로그인했는지 확인한 다음 앱에서 새로고침을 실행해 주세요. API 키 로그인은 ChatGPT 구독 사용 한도와 다르므로 지원 대상이 아닙니다.

위젯 목록에 앱이 없어요.

앱을 한 번 실행해 사용량이 갱신될 때까지 기다린 뒤 위젯 편집 화면을 다시 열어 주세요.

오래된 값이 보여요.

네트워크 또는 Codex 연결이 실패하면 앱은 마지막으로 확인된 값을 유지합니다. 연결을 확인한 뒤 수동 새로고침을 실행해 주세요.

앱 데이터는 어디에 저장되나요?

위젯 표시와 최근 사용 현황을 위한 캐시는 사용자의 Mac 안에만 저장되며 개발자가 운영하는 서버로 전송되지 않습니다.
