CodeAgentGauge(이하 “앱”)는 macOS에서 사용자의 AI 코딩 사용 한도와 토큰 사용 현황을 표시하는 독립 실행형 유틸리티입니다. 이 앱은 연결된 서비스 제공자와 제휴되어 있거나 해당 제공자의 승인·후원을 받은 제품이 아닙니다.

1. 수집 및 사용

앱은 개발자 또는 개발자가 운영하는 서버로 사용자의 개인정보를 수집, 저장, 전송하거나 판매하지 않습니다.

앱은 사용자가 macOS의 표준 폴더 선택 패널로 직접 허용한 AI 코딩 활동 폴더(기본 위치 ~/.codex)에서 sessions와 archived_sessions 하위 폴더의 JSONL 사용량 기록만 사용자의 기기 안에서 읽어 화면과 위젯에 표시합니다. 선택한 폴더는 읽기 전용으로 접근하며, 접근 권한은 보안 범위 북마크로 기기에 보관됩니다. 최근 사용량과 위젯 표시를 위한 캐시는 기기에만 저장되며 개발자에게 전송되지 않습니다.

앱은 사용 한도 표시에 필요한 기록 속 요금제 범주(plan_type)를 기기 안에서 처리할 수 있지만, 계정 식별정보, 계정 이메일, 인증 파일, OAuth 토큰 또는 API 키를 읽거나 저장하지 않습니다. 호환 도구나 서비스의 기존 로그인 연결을 사용하지 않고, 외부 앱이나 명령줄 실행 파일을 시작하지 않습니다.

심사용 데모 모드는 앱에 내장된 가상 샘플 데이터만 사용하며, 사용자의 계정이나 실제 사용량 정보를 필요로 하지 않습니다.

비용 추정 기능은 유럽중앙은행(ECB)이 공개하는 환율 데이터를 내려받을 수 있습니다. 이 요청에는 사용자 계정 정보나 사용량 정보가 포함되지 않습니다.

2. 제3자 서비스

AI 코딩 사용량 기록은 사용자가 별도로 사용하는 호환 도구가 생성할 수 있습니다. 해당 도구와 서비스의 데이터 처리에는 각 제공자의 개인정보 처리방침이 적용됩니다. CodeAgentGauge는 해당 제공자의 서비스에 접속하지 않으며, 사용자가 선택한 로컬 JSONL 기록을 개발자 또는 제3자에게 전송하지 않습니다.

3. 추적 및 광고

앱은 광고를 표시하지 않으며, 사용자를 추적하거나 제3자 광고·분석 SDK를 사용하지 않습니다.

4. 데이터 보관 및 삭제

앱은 최근 사용량과 위젯 표시를 위한 로컬 캐시를 사용자의 Mac에 보관할 수 있습니다. 앱을 제거하거나 앱의 로컬 데이터를 삭제하면 해당 캐시를 제거할 수 있습니다.

ENGLISH SUMMARY

Privacy Policy Summary

CodeAgentGauge reads only JSONL usage records under the sessions and archived_sessions subfolders of a local AI coding activity folder that the user explicitly selects through the macOS folder picker. Access is read-only and retained on the Mac with an app-scoped security bookmark. The app may process the plan_type category contained in those records on-device to label usage limits, but it does not read account identity, email, authentication files, OAuth tokens, or API keys; use an existing service login connection; launch an external app or command-line executable; or send the selected records to the developer or any third party. The app is independent and is not affiliated with, endorsed by, or sponsored by any compatible tool or service provider. Its reviewer demo uses only bundled fictional sample data. The app may request public exchange-rate data from the European Central Bank without including account or usage information.

For privacy questions, contact h0tshin2@gmail.com.
